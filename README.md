# CombinatoricsCalculator
Калькулятор комбинаторики

Программа для вычисления основных комбинаторных величин.

## Возможности

## Программа позволяет вычислять:

1. Перестановки — количество способов упорядочить все элементы.
2. Размещения — количество способов выбрать и расположить несколько элементов из общего числа.
3. Сочетания — количество способов выбрать несколько элементов без учёта порядка.

## Используемые формулы

- Перестановки: "P(n) = n!"
- Размещения: "A(n, k) = n! / (n - k)!"
- Сочетания: "C(n, k) = n! / (k! * (n - k)!)"

## Запуск программы

1. Скачайте репозиторий на компьютер.
2. Откройте файл проекта в среде разработки.
3. Запустите программу.

## Управление

После запуска программы появляется меню:

- "1" — Перестановки
- "2" — Размещения
- "3" — Сочетания
- "4" — Выход

Для вычислений необходимо ввести значение "n", а для размещений и сочетаний — дополнительно значение "k".

## Проверка данных

Программа проверяет корректность введённых значений, не допускает отрицательных значений и контролирует допустимый диапазон вычислений для предотвращения переполнения.

После выполнения вычисления программа возвращается в главное меню.
